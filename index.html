I build web apps that stay fast when the data gets heavy: clean React on the front, reliable Node.js APIs behind it. 

I am a full-stack developer with 8+ years of experience. I started out building desktop software in VB.NET, moved to the web with .NET MVC and React, and since 2021 I have been a Senior Web Developer at Pure Broking, building the screens and services behind financial products.

Most of my day is React.js and Redux on the front end and Node.js with Express on the back end, with PostgreSQL and MSSQL underneath. I care about speed, from code splitting and bundle tuning to lean APIs, and I use AI tools like Claude and ChatGPT to ship faster without cutting corners on code review.
